包含斯里兰卡、暹粒与吴哥窟、马来西亚与新加坡三份独立方案。马新方案附兰卡威海岛版与迪沙鲁冲浪版。

## 查看网页

用浏览器打开 `index.html`。样式、插画和交互均在这一文件内，无需安装软件或配置构建环境。网页可离线阅读；外部官方链接需要联网。

可切换目的地和马新路线、设置抵达日期、勾选行前事项，并打印全部方案。日期输入代表当地抵达日，不含国际航班飞行时间。勾选和日期只保存在当前浏览器，清除浏览器数据后会重置。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个公开仓库，或选择合适的已有仓库。
2. 解压部署包，将 `index.html`、`.nojekyll` 和 `README.md` 上传到仓库根目录并提交。不要上传 ZIP 本身来代替解压文件。
3. 打开仓库的 **Settings → Pages**。
4. **Source** 选择 **Deploy from a branch**，选择实际保存文件的分支（新仓库通常为 `main`）与 **/ (root)**，点击 **Save**。
5. 等待部署完成，在 Pages 页面点击 **Visit site**。

普通项目网址为 `https://<用户名>.github.io/<仓库名>/`。如果改用 `/docs` 发布，把网页文件放在仓库的 `docs` 顶层，并在 Pages 中选择对应目录。

GitHub Free 通常要求公开仓库。Pages 发布后的网页可被公众访问，请勿加入护照号、机票订单、私人联系方式等信息。当前交付包没有这些资料。

官方说明：[配置发布来源](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)、[创建 Pages 网站](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)。
